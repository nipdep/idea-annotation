Annotator Guidelines

Core Objects

Annotate only two objects: Concepts (entities) and Arguments (canonical statements). No relations or extra structure.

Concepts

Choose the most specific category available. You can stop at any level if no finer match exists.

Required fields: label, category, roles.

Arguments

Required fields: canonical text and argument type. Concept refs are optional.

Required types for submission: issue, idea, approach, claim.

Semantic Normalization Rules

Rule 1: Remove epistemic modifiers (e.g., “significantly”, “we believe”, “suggests that”).

Rule 2: Collapse enumerations when possible or create one assertion per comparison dimension.

Rule 3: Make implicit subjects explicit.

Canonical form test: A competent reader should judge support or contradiction using the paper alone.

Suggested Flow

Issue + backing → Idea → Approach → Experiments → Claims + warrants.
