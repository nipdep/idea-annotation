Annotator Guidelines

Core Objects

Annotate three objects: Artifacts (entities), Arguments (canonical statements), and Descriptors.

Artifacts

Choose the most specific category available. You can stop at any level if no finer match exists.

Required field: label. Category is optional and defaults to base class artifact.

Arguments

Type is optional and defaults to base class argument.

Suggested coverage: issue, idea, approach, and claim.

Descriptors

Required field: source refs. Type is optional and defaults to base class description.

Descriptor type values: elaboration, circumstance, solutionhood, cause, result, purpose, condition, interpretation, evaluation, restatement, summary.

Semantic Normalization Rules

Rule 1: Remove epistemic modifiers (e.g., “significantly”, “we believe”, “suggests that”).

Rule 2: Collapse enumerations when possible or create one assertion per comparison dimension.

Rule 3: Make implicit subjects explicit.

Canonical form test: A competent reader should judge support or contradiction using the paper alone.

Suggested Flow

Issue + backing → Idea → Approach → Experiments → Claims + warrants.
